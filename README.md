# German-Elite-Cups1.0
GERMAN ELITE CUPS (GEC) ist eine professionelle Esports-Plattform für EA FC Pro Clubs. Organisiere Teams, Cups, Ligen, Matches und Transfers, finde Free Agents und verwalte Kader. Spieler erhalten Profile, Statistiken und Marktwerte, während Staff und Management den gesamten Spielbetrieb steuern.
